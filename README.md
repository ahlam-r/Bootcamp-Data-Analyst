
# Bootcamp Data Analyst Portfolio / Portafolio Bootcamp Data Analyst

## Español

Este repositorio muestra mi progreso y proyectos realizados durante el bootcamp de Data Analyst. Cada carpeta corresponde a un sprint y refleja la evolución de mi aprendizaje, desde consultas SQL hasta análisis y visualización de datos con Python, Power BI y MongoDB.

### Estructura del repositorio
- **Sprint 2, 3 y 4:** Consultas y proyectos en SQL
- **Sprint 5 y 6:** Proyectos y dashboards en Power BI
- **Sprint 7 y 8:** Análisis y visualización de datos con Python (Jupyter Notebooks)
- **Sprint 9:** Introducción y ejercicios con MongoDB
- **Sprint 10:** Proyecto final integrador (análisis de redes sociales vs productividad)

### Cómo usar este repositorio
1. Explora cada carpeta para ver los entregables de cada sprint.
2. Los archivos `.ipynb` contienen análisis y visualizaciones en Python.
3. Los archivos `.sql` muestran consultas y scripts de bases de datos.
4. Los dashboards de Power BI están documentados en sus respectivas carpetas.

### Tecnologías utilizadas
- SQL
- Python (Pandas, Matplotlib, Seaborn, etc.)
- Power BI
- MongoDB
